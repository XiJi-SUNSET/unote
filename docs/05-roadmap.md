# 路线图

每个阶段只有一个目标。**没有达成就不要开始下一个**——这是防止这个项目变成"又一个半成品笔记 App"的唯一手段。

## 阶段总览

| 阶段 | 目标 | 判定标准（DoD） | 目标版本 |
|---|---|---|---|
| **M0** 设计 | 想清楚，不写代码 | 三份文档定稿，三个产品问题有答案 | — |
| **M1** 闭环 | 能真的用来上课 | 连续记 20 节真实课堂笔记，没遇到阻塞性 bug | `0.1.0` |
| **M2** 审美 | 好看 | 截图发出去，有人问"这是什么 App" | `0.2.0` |
| **M3** 数据 | 不怕丢 | 导出的 zip 在电脑上解压，Typora 能直接打开 | `0.3.0` |
| **M4** 发布 | 能给陌生人用 | 陌生人从 Release 下载，不读 README 也能上手 | `1.0.0` |

## M1 · 核心闭环（`0.1.0`）

**目标：能替代纸本，完成一节完整的课。**

- [ ] 工程脚手架：Vite + React + TS strict + Capacitor Android
- [ ] 移除 `INTERNET` 权限，跑通空壳安装
- [ ] 数据层：Dexie schema v1 + NoteRepo / AssetRepo
- [ ] 列表屏：时间线、置顶、空态
- [ ] 编辑屏：textarea、自动保存（400ms debounce + 失焦 flush）、标题联动
- [ ] 预览屏：markdown-it + DOMPurify + 图片渲染
- [ ] 插图：选图 → 压缩 → 插入 `asset:` 引用
- [ ] 冷启动恢复：上一篇 / 草稿
- [ ] 返回键与边到边适配

**DoD**：连续 20 节真实课堂笔记，无数据丢失、无输入卡顿。

## M2 · 审美（`0.2.0`）

**目标：从"能用"到"想用"。**

- [ ] 设计 token 落地，替换所有字面量
- [ ] 壁纸：选择、裁剪、两档存储、模糊层、scrim
- [ ] 明暗自适应（亮度 → 文字色 + 强调色提取）
- [ ] 横屏双栏布局（CSS Grid，组件树不变）

- [ ] 图标与启动页

**DoD**：截图发到群里，有人主动问"这是什么 App"。

## M3 · 数据（`0.3.0`）

**目标：敢往里存东西。**

- [ ] 全文搜索（内存索引）+ 搜索结果节选
- [ ] 标签：添加、筛选、重命名
- [ ] 导出：Worker + fflate，进度条，系统分享
- [ ] 导入：合并 / 覆盖两种模式，结果报告
- [ ] 每日本地快照（保留 7 份）+ 恢复入口

**DoD**：导出 zip → 电脑解压 → Typora 打开 → 内容、图片、frontmatter 全对；再导入回手机，内容一致。

## M4 · 发布（`1.0.0`）

**目标：陌生人能用。**

- [ ] 应用图标、商店截图、README 截图
- [ ] 签名配置与 `keystore` 安全存放（不进仓库）
- [ ] GitHub Actions：lint / typecheck / test / build apk
- [ ] CI 断言：APK 不含 `INTERNET` 权限
- [ ] Release 流程：tag → 自动构建 → 附 APK
- [ ] 首次启动引导（一句话，不是教程）
- [ ] 中文 README + 英文摘要

**DoD**：陌生人从 Release 页下载 APK，不读文档也能写出第一篇笔记并导出。

## 时间预算（单人，业余）

| 阶段 | 估时 | 说明 |
|---|---|---|
| M0 | 3–5 天 | 文档 + 视觉稿 |
| M1 | 2–3 周 | 最重的一段，编辑器与保存逻辑容易低估 |
| M2 | 2–3 周 | 壁纸适配的坑比想象多 |
| M3 | 2 周 | 导入的边界情况占一半时间 |
| M4 | 1 周 | 签名与 CI |

> 如果只有周末能写，把每一档乘 2.5。

---

## 砍功能顺序

时间不够时，**从上往下砍**，不要跳着砍：

1. 标签
2. 搜索高亮与节选
3. 单篇壁纸覆盖
4. 横屏双栏
5. 代码块语法高亮
6. 本地快照（保留导出即可）

**永远不砍**：自动保存、ZIP 导出、图片压缩、断网保证。

这四件事是"数据不会丢"和"它真的离线"的全部承诺。少一个，这个产品就没有存在理由。
