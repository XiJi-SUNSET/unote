# 路线图

每个阶段只有一个目标。**没有达成就不要开始下一个**——这是防止这个项目变成"又一个半成品笔记 App"的唯一手段。

## 阶段总览

| 阶段 | 目标 | 判定标准（DoD） | 目标版本 |
|---|---|---|---|
| **M0** 设计 | 想清楚，不写代码 | 三份文档定稿，三个产品问题有答案 | — |
| **M1** 闭环 | 能真的用来上课 | 连续记 20 节真实课堂笔记，没遇到阻塞性 bug | `0.1.0` |
| **M2** 审美 | 好看 | 截图发出去，有人问"这是什么 App" | `0.2.0` |
| **M3** 数据 | 不怕丢 | 导出的 zip 在电脑上解压，Typora 能直接打开 | `0.3.0` |
| **M4** 发布 | 能给陌生人用 | 陌生人从 Release 下载，不读 README 也能上手 | `1.0.0` |

## 砍功能顺序

时间不够时，**从上往下砍**，不要跳着砍：

1. 标签
2. 搜索高亮与节选
3. 单篇壁纸覆盖
4. 横屏双栏
5. 代码块语法高亮
6. 本地快照（保留导出即可）

**永远不砍**：自动保存、ZIP 导出、图片压缩、断网保证。

这四件事是"数据不会丢"和"它真的离线"的全部承诺。少一个，这个产品就没有存在理由。
