# 视觉与交互规范

> 状态：Proposed（v0.1 基线，M2 迭代）
> 关联：[01-tech-stack.md](01-tech-stack.md) §4

---

## 1. 原则

1. **内容优先，界面退后。** 打开 App 时，用户应该先看到字，再看到 UI。
2. **安静。** 没有弹窗、没有红点、没有"欢迎使用"的引导页。提示只出现在它必须出现的地方，且可以忽略。
3. **克制。** 一个页面最多一个强调色。动效只在"状态变化"时出现，不做装饰性动画。
4. **手感。** 点击有 60ms 的按下反馈；滚动跟手；键盘弹起时输入行不被遮挡。

## 2. 设计 Token

唯一真源：`src/styles/tokens.css`。组件里**不允许**出现字面量颜色/圆角/间距。

```css
:root {
  /* 间距：4 的倍数，只用这 7 档 */
  --sp-1: 4px;  --sp-2: 8px;  --sp-3: 12px; --sp-4: 16px;
  --sp-5: 24px; --sp-6: 32px; --sp-7: 48px;

  /* 圆角 */
  --r-sm: 10px;  --r-md: 16px;  --r-lg: 22px;  --r-full: 999px;

  /* 字阶（以 17px 为基准，符合移动端阅读习惯） */
  --fs-xs: 12px;  --fs-sm: 14px;  --fs-base: 17px;
  --fs-lg: 20px;  --fs-xl: 26px;  --fs-2xl: 34px;

  /* 行高：正文 1.75，标题 1.3 */
  --lh-body: 1.75;  --lh-tight: 1.3;

  /* 动效 */
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
  --dur-fast: 120ms;  --dur-base: 220ms;  --dur-slow: 380ms;
}
```

### 颜色

不写死一套"浅色/深色"，而是用**语义变量**，由壁纸的明暗决定取值：

```css
[data-scheme="light"] {
  --bg:        color-mix(in srgb, var(--wall-avg) 12%, #fff);
  --surface:   rgb(255 255 255 / 0.72);
  --text:      #1a1a1a;
  --text-dim:  #6b6b6b;
  --line:      rgb(0 0 0 / 0.08);
  --accent:    var(--wall-accent);
}

[data-scheme="dark"] {
  --bg:        color-mix(in srgb, var(--wall-avg) 14%, #0d0d0f);
  --surface:   rgb(22 22 24 / 0.66);
  --text:      #ededed;
  --text-dim:  #9a9a9a;
  --line:      rgb(255 255 255 / 0.10);
  --accent:    var(--wall-accent);
}
```

- `--wall-avg`：壁纸的平均色（从缩略图算，见 §4）
- `--wall-accent`：壁纸的主色（`ColorThief` 思路的简化实现，量化到 12 色再取最高频）

**强调色来自壁纸本身**，这是"壁纸能换、但整体不花"的关键：全站只有一个彩色来源。

## 3. 字体

### 3.1 策略：不打包中文字库

一套中文 Web 字体（哪怕子集化）动辄 3–9MB，会吃掉 APK 预算的一半，而且首屏要等字体加载。**v1 用系统字体栈**：

```css
--font-ui: system-ui, "MiSans", "HarmonyOS Sans SC", "PingFang SC",
           "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
--font-reading: "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", serif;
--font-mono: ui-monospace, "JetBrains Mono", "Cascadia Code", monospace;
```

好处：零体积、零加载、与系统一致（用户手机上的中文字体已经是厂商调过的）。

### 3.2 唯一的例外：拉丁展示字体

标题里的英文/数字用一个**自托管 woff2 子集**（只含拉丁字母 + 数字 + 常用符号），体积控制在 **30KB 内**。候选：Instrument Serif、Fraunces、Newsreader。

用途仅限：启动页 wordmark、笔记标题中的英文段、设置页的版本号。**不用于正文。**

### 3.3 排版细节

| 项 | 值 | 说明 |
|---|---|---|
| 正文宽度 | ≤ 38em | 横屏时限制，避免一行太长 |
| 段距 | 1em | 用 `margin` 而非空行 |
| 中文标点 | 不做标点挤压 | Android WebView 的 `text-spacing-trim` 支持不稳定 |
| 首行缩进 | 无 | Markdown 语境下缩进是语义，不装饰 |
| 数字 | `font-variant-numeric: tabular-nums`（表格/时间） | |
| 选中色 | `color-mix(in srgb, var(--accent) 30%, transparent)` | |

## 4. 壁纸系统

这是整个视觉的核心，也是最容易做崩性能的地方。

### 4.1 图层

```
┌─────────────────────────────┐
│ 0. 底色（--bg）              │  ← 壁纸加载前的兜底，避免白闪
├─────────────────────────────┤
│ 1. 壁纸图（预先缩放+模糊）    │  position: fixed; inset: 0; filter: blur(24px) saturate(1.1)
├─────────────────────────────┤
│ 2. scrim（可调不透明度）      │  linear-gradient(180deg, rgba(0,0,0,.25), rgba(0,0,0,.55))
├─────────────────────────────┤
│ 3. 内容卡片（半透明 surface） │  不用 backdrop-filter
└─────────────────────────────┘
```

**关键决策（2026-10 修订）：卡片用 `backdrop-filter` 做真玻璃，但提供性能开关。**

最初的设计是"壁纸先模糊、卡片只半透明"，理由是 `backdrop-filter` 在低端机上昂贵。实际观感差太多：没有局部模糊，玻璃就是一层面膜。现在的做法：

- 壁纸层保持清晰，只按设置做整体模糊（0–30px）
- 卡片 / 面板 / 顶栏 / 工具栏用 `blur(var(--blur)) saturate(1.45)`
- 设置里可以一键关掉毛玻璃（`data-glass="off"`），退化为不透明面板
- **阅读/编辑屏例外**：背景先压暗（`--scrim` + blur 6px），再浮起一张 `--sheet` 的纸面（22px 圆角 + 大阴影），结构照抄 Exterior 的 `modal + modal-card`。正文 16px / 行高 1.8 / 行宽受卡片约束

### 4.1 材质参数全部交给用户

照 Exterior 的 `GLASS_DEFAULTS` 做的五个滑杆（设置 → 壁纸），实时写 CSS 变量，不重启、不重绘整页：

| 滑杆 | 变量 | 默认 | 范围 | 管什么 |
|---|---|---|---|---|
| 壁纸遮罩 | `--overlay` | 22% | 0–90% | 壁纸上那层同色薄纱，越高越"退后" |
| 壁纸模糊 | `--bg-blur` | 0px | 0–30px | 壁纸本身的模糊 |
| 界面模糊 | `--blur` | 16px | 0–30px | 卡片/面板的 `backdrop-filter` 半径 |
| 卡片不透明度 | `--glass` | 62% | 20–95% | 卡片底色 alpha |
| 阅读纸面 | `--sheet` | 90% | 60–100% | 阅读/编辑那张纸的 alpha |

遮罩颜色跟主题走（浅色用奶油、深色用暖黑），所以它是一层"同色薄纱"而不是灰罩——这是 Exterior 的做法，比加黑色遮罩干净。

`--glass-strong` 不单独给滑杆，由卡片值 +0.24（上限 0.96）派生，避免出现"卡片透、工具栏不透"的割裂。

### 4.2 壁纸处理管线

```
用户选图
  → 裁剪为屏幕比例（竖屏 9:19.5，横屏 19.5:9）
  → 生成两档：
       thumb  360px 长边  → 用作列表页缩略与平均色计算
       full   1440px 长边 → 全屏显示
  → 存为 WebP（quality 0.8），写入 assets 表
  → 计算平均色 + 主色，写入 settings
```

- 模糊在 CSS 层做（`filter: blur()`），不做"预渲染模糊图"——省一次编码，且不同屏幕尺寸不用重算。
- 切换壁纸时用 `opacity` 交叉淡入 380ms，避免闪白。

### 4.3 明暗自适应

```
取 thumb 的平均亮度 L（Rec.709 加权）。注意反直觉：**壁纸越亮，越要用深色文字**。映射如下：

| 壁纸亮度 | scrim | 文字 |
|---|---|---|
| L > 0.6（亮） | `rgba(255,255,255,.35)` 提亮 | `--text: #1a1a1a` |
| 0.3 < L ≤ 0.6 | 不加 | 按主色冷暖微调 |
| L ≤ 0.3（暗） | `rgba(0,0,0,.45)` 压暗 | `--text: #ededed` |

用户可手动覆盖（设置里有"跟随壁纸 / 强制浅色 / 强制深色"三档）。

## 5. 布局

### 5.1 竖屏（默认）

```
┌───────────────────────────┐
│ ‹   标题            ⋯     │  顶栏 56dp，透明，滚动时渐变出模糊底
├───────────────────────────┤
│ 高数 · 计网 · 大物 · +    │  课程切换条，横向滚动，当前项加粗
├───────────────────────────┤
│                           │
│   正文（--font-reading）   │  左右 padding 20px
│                           │
│                           │
├───────────────────────────┤
│ B  I  H  •  "  🖼   ⌨️     │  工具栏，贴在键盘上方
└───────────────────────────┘
```

- 顶栏在内容滚动超过 8px 后，背景从透明过渡到 `--surface`（`--dur-fast`）。
- 工具栏通过 `visualViewport.height` 计算位置，键盘弹起时**贴在键盘上沿**，收起时贴屏幕底部。
- 字数/保存状态放在顶栏副标题位，不占正文空间。

### 5.2 横屏（≥ 600dp 宽）

```
┌──────────────┬────────────────────────────┐
│ 搜索          │  ‹  标题             ⋯     │
├──────────────┼────────────────────────────┤
│ ● 笔记 A      │                            │
│   14:32       │   正文                     │
│               │                            │
│ ● 笔记 B      │                            │
│   昨天        │                            │
│               │                            │
└──────────────┴────────────────────────────┘
   320dp 固定           剩余自适应
```

- 用 CSS Grid，只改 `grid-template-columns`，**组件树不变**（见架构 §4.5）。
- 左侧列表可折叠（点标题栏左侧按钮），折叠后回到单栏。
- 平板/折叠屏展开态复用这个布局，阈值 600dp。

### 5.3 安全区

从第一天就按 edge-to-edge 写：

```css
padding-top: env(safe-area-inset-top);
padding-bottom: max(env(safe-area-inset-bottom), var(--sp-2));
```

Android 15 强制 edge-to-edge，事后补是灾难。

## 6. 动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 页面进入（新笔记） | 220ms | `--ease-out` | 从下方 8px + 淡入，不做全屏推拉 |
| 页面返回 | 180ms | `--ease-out` | |
| 底栏出现（键盘弹起） | 120ms | `--ease-out` | 跟随键盘，不要延迟 |
| 壁纸切换 | 380ms | `--ease-in-out` | 交叉淡入 |
| 保存状态点 | 150ms | linear | `○` → `·` 的形变 |
| 列表项按下 | 60ms | linear | `scale(0.985)` |

**禁止**：视差滚动、粒子、渐变流动、加载骨架屏的 shimmer 动画（首屏够快，不需要）。

尊重系统设置：`@media (prefers-reduced-motion: reduce)` 时全部降为 0ms。

## 7. 空态与边界

| 状态 | 呈现 |
|---|---|
| 首次启动 | 一句话：「写点什么。」下面一行灰色小字：「内容只存在这台手机上。」不弹教程 |
| 搜索无结果 | 「没有匹配的笔记」+ 清空搜索的按钮 |
| 图片加载失败 | 占位块（虚线框 + 图标 + alt 文本），高度按 4:3 预留，避免跳动 |
| 保存失败 | 顶栏出现一次性的红点 + 点击展开说明，**不弹窗** |
| 存储将满 | 设置页一行提示，不打断写作 |

---

## 8. 无障碍

- 正文对比度 ≥ 4.5:1（壁纸场景下，用 scrim 保证，不靠运气）
- 点击目标 ≥ 44 × 44dp
- 支持系统字号缩放至 200%：布局用 `rem`，断点用 `em`
- 所有图标按钮有 `aria-label`
- 输入框有可见 focus 环（用 `--accent`，2px）
