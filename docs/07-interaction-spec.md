# 交互规格

> 状态：Proposed（M1 实现依据）
> 来源：从作者另一个项目 Exterior 的交互中提炼（见 [06-prior-art.md](06-prior-art.md) 同类分析），**按轻量离线 APK 的边界做了裁剪**。
> 关联：[02-architecture.md](02-architecture.md) §4.6 · [04-design-system.md](04-design-system.md) §5

---

## 1. 只学一件事：上下文即默认值

Exterior 里新增条目的分组/日期/父级，**都不是问出来的，是继承出来的**：

| 你站在哪 | 新条目自动落到 |
|---|---|
| 分组视图的「高数」tab | 高数 |
| 日历视图的 10 月 17 日 | 10-17 |
| 层级视图的 `/算法` 目录 | `/算法` 下的子项 |
| 其它视图 | 上次用过的值 |

Unote 原样照搬，只换一个维度：

| 你站在哪 | 新笔记自动落到 |
|---|---|
| 课程「高等数学」的列表里 | 高等数学 |
| 横屏左侧选中「高等数学」 | 高等数学 |
| 搜索 / 全部（跨课程） | `settings.lastCourseId` |
| 冷启动恢复上一篇 | 那一篇的课程 |

**结论：新建笔记不弹课程选择器。** 课程只在两个时刻出现——徽章显示，和你想改的时候点一下。

## 2. 两个入口，都不问课程

### 2.1 主路径：冷启动

```
点图标 → 直接回到上一篇 → 光标在末尾 → 写
```

0 次点击，0 次选择。这是 90% 的使用场景。

### 2.2 次路径：底部快速记录条

列表页底部常驻一条输入框，模仿 Exterior 的「记点什么…」：

```
┌──────────────────────────────┐
│ 记点什么…              ▸     │  单行，回车即存
└──────────────────────────────┘
```

| 行为 | 规则 |
|---|---|
| 回车 | 立即创建一条笔记，首行即标题，落在当前课程的「今天」位置 |
| 保存后 | 输入条清空、**保持焦点**（连记时不用反复点），新条目滚到可视区 |
| 需要多行 / 插图 | 点右侧 `▸` 展开成全屏编辑器，已输入内容带过去 |
| 课程 | 不显示、不询问——继承 §1 的上下文 |

> 与 Exterior 的差异：它保存后 `blur()` 收键盘（为了看刚插入的条目）。我们保留焦点，因为输入条本来就在键盘上方，连记更顺。代价是新条目可能被键盘挡住，用滚动补偿。

## 3. 三个屏

### 3.1 列表屏

```
┌───────────────────────────────┐
│ 搜索…                     ⋯   │  顶栏
├───────────────────────────────┤
│ 全部 · 高数 · 计网 · 大物 · + │  课程 chips，横向滚
├───────────────────────────────┤
│ ┌───────────────────────────┐ │
│ │ 为什么 TCP 要三次握手      │ │  NoteCard
│ │ 老师说两次不够，因为…      │ │
│ │ 10:32  #待查               │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ …                         │ │
├───────────────────────────────┤
│ 记点什么…                ▸    │  快速记录条
└───────────────────────────────┘
```

- 卡片**不挂常驻按钮**。要做的事收在两个地方：右滑露出「置顶 / 删除」，其余进阅读屏。
- 点击卡片 = 打开阅读屏（**默认渲染好的 Markdown**，点右上角铅笔才进源码编辑）。
- **右滑卡片**露出两个操作，宽度 132px，滑过 56px 自动吸附；滑动中不触发打开，展开时点一下先收起。
- chips 点击 = 切课程（筛选），`stopPropagation` 同理，不会误开笔记。
- 「全部」是 chip 之一，不是独立 tab；它跨课程，新建时落到 `lastCourseId`。

### 3.2 编辑屏

```
┌───────────────────────────────┐
│ ‹   高数 ▾          👁    ⋯   │  课程徽章可点（就地改归属）
├───────────────────────────────┤
│                               │
│  正文（textarea，预览态时换成   │
│       渲染结果，同屏切换）      │
│                               │
├───────────────────────────────┤
│  B   I   H   •   "   🖼        │  工具栏贴键盘
└───────────────────────────────┘
```

| 元素 | 交互 |
|---|---|
| `‹` | 返回列表，先 flush 未存的改动 |
| 课程徽章 | 点开**横向 chips 弹层**改归属（不跳页），改完自动保存 |
| ✏️ / 👁 | 阅读 ↔ 源码。**打开即阅读态**，只有点铅笔才进编辑 |
| 图片 | 选图 → 压缩 → 插入 `asset:` 引用 |

- 阅读区用近乎不透明的纸面（`--paper`），壁纸再花也不影响可读性。
- 进入编辑时**不自动聚焦**（触屏会盖住半屏），用户点哪输哪。
- 返回时若有未保存改动，先 flush；实在失败才提示。

### 3.3 设置屏

壁纸、主题（跟随壁纸/浅/深）、字号、回收站、导出、导入、关于。没有 AI、没有同步、没有账号。

## 4. 卡片行为矩阵（简化后）

| 卡片状态 | 左侧 | 右侧 | 点击 |
|---|---|---|---|
| 普通 | — | 置顶图钉（若已置顶） | 打开（预览态） |
| 已删除 | — | — | 只读打开 |

没有完成圆点（笔记不是任务），没有 hover 动作（触屏没有 hover），没有右键菜单。

---

## 5. 删除 = 回收站，保留 30 天

```
点删除 → deletedAt 打时间戳（不出确认弹窗）
   ↓
设置 → 回收站 → 恢复 / 彻底删除
   ↓
30 天后自动清理（启动时扫一次）
```

不学 Exterior 的 `purged` 墓碑——那东西只服务多端同步（防对端复活），我们单机不需要。

导出时**不导出回收站内容**，但导出包里的 id 保持原样，重新导入不会与回收站里的条目冲突。

## 6. 触屏规则（全部从 Exterior 的踩坑里抄）

| 规则 | 原因 |
|---|---|
| 不依赖 `:hover` 显形按钮 | 触屏上 hover 永远是"看不见的盲区" |
| 点击目标 ≥ 44dp，用透明伪元素扩命中区 | 视觉不变，手感变大 |
| 全站补 `:active` 的 `scale(.95)` + 透明度 | 触屏没有 hover，按下必须有反馈 |
| 进入编辑**不自动 focus** | 键盘会盖住下半屏 |
| `100dvh` 而非 `100vh` | 移动浏览器地址栏收起会变高 |
| 不引入滑动 / 长按 / 双击 | 整套交互只用可见按钮，降低发现成本 |
| 底部留 `env(safe-area-inset-bottom)` | 手势条区域 |

## 7. 明确不学的部分

| Exterior 的东西 | 为什么不学 |
|---|---|
| **AI 状态机**（`ai_status` / `needs_review` / `approved`） | 产品明确不做 AI |
| **AI 草稿与写保护**（`ai_draft` / `ai_protected`） | 同上 |
| **快速操作 chips、监看窗、SSE 流** | 同上 |
| **层级树**（`parent_id` / `is_project`） | 课程只有一层，树是给"项目"用的 |
| **status 三态**（inbox/active/done） | 笔记不是待办；状态轴只会增加心智负担 |
| **revisions 快照** | 那是给 AI 回滚用的，我们没有 AI |
| **purged 墓碑** | 只服务同步，单机不需要 |
| **六视图** | 我们只有列表 + 编辑 + 设置 |
| **卡片上的 hover 动作** | 触屏不可达；我们把操作收敛进编辑屏 |
| **monorepo / 服务端 / Docker** | 无网单机，一个包就够 |

## 8. 验收清单（M1 结束时逐条过）

- [ ] 从冷启动到光标可用，全程没有出现课程选择
- [ ] 在「高数」里点快速记录，新笔记自动是高数，不需要二次设置
- [ ] 横屏左侧选「计网」，新建的笔记落到计网
- [ ] 课程徽章点开能就地改归属，改完刷新仍在
- [ ] 编辑屏 `👁` 切换预览时，光标位置与滚动位置不丢
- [ ] 键盘弹起时工具栏贴住键盘上沿，正文最后一行不被遮
- [ ] 删除后能在回收站找回；恢复后课程归属不变
- [ ] 导出包里没有回收站内容，导入后不产生重复课程
- [ ] 全流程没有出现任何"AI""同步""登录"字眼
